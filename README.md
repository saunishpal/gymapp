# Iron Pulse Fitness

A modern, conversion-focused fitness landing page built for a gym or personal fitness coach brand. This project is designed as a portfolio-ready business website demo with interactive UI, pricing plans, lead-generation sections, and a built-in chatbot for answering common user queries.

## Live Project Purpose

This website is created to showcase the ability to build:

- modern business landing pages
- responsive websites for service-based brands
- pricing and lead-generation sections
- interactive chatbot support
- polished UI for fitness and wellness businesses

## Project Overview

Iron Pulse Fitness is a high-energy landing page concept for a gym / fitness coach business. It is designed to help visitors:

- understand the brand and coaching style
- explore training programs
- view pricing plans
- see trust-building content and testimonials
- contact the coach or business easily
- get answers through a chatbot

## Features

- Responsive landing page
- Sticky navigation bar
- Mobile hamburger menu
- Active navigation highlight on scroll
- Hero section with stats
- About coach section
- Training programs section
- Transformation highlights section
- Why choose us section
- Membership pricing cards
- Client testimonials
- Call-to-action section
- Contact / inquiry form
- Success message on form submission
- Scroll reveal animations
- Loading screen
- Scroll-to-top button
- Fitness chatbot for quick assistance
- Custom logo and favicon support

## Chatbot Capabilities

The chatbot can respond to common questions such as:

- membership plans
- pricing
- weight loss program
- online coaching
- timings
- how to join
- diet / nutrition guidance
- muscle gain

## Tech Stack

- HTML5
- CSS3
- JavaScript
